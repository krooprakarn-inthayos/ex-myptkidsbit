# PTKidsBIT Mission — บล็อคนำทางสำหรับภารกิจส่งด่วน

Extension สำหรับหุ่น **PTKidsBIT** (micro:bit) ที่รวม **บล็อคเดิมทั้งหมด** ของ
[pxt-PTKidsBIT-Robot](https://github.com/iBuilds/pxt-PTKidsBIT-Robot) v1.6.5 (โดย PTBOT)
และเพิ่มหมวดใหม่ **"ภารกิจส่งด่วน"** ที่ให้หุ่นหาเส้นทางและวิ่งเองจากจุดหนึ่งไปอีกจุดหนึ่งบนสนามแข่งขัน PT KidsBiT ภารกิจส่งด่วน (240 × 120 ซม.)

## ติดตั้ง

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (เช่น `krooprakarn-inthayos/pxt-PTKidsBIT-Mission`)
2. เปิด https://makecode.microbit.org → New Project → Extensions
3. วาง URL ของ repo แล้วกดเพิ่ม

> **ห้ามใส่ Extension `PTKidsBIT-Robot` ตัวเดิมในโปรเจกต์เดียวกัน** ชื่อคำสั่งจะชนกันและโปรเจกต์คอมไพล์ไม่ผ่าน ตัวนี้มีบล็อคเดิมครบแล้ว

## จุดในสนาม (มุมมองหุ่นที่ START หันหน้าเข้าสนาม · ภาพคร่าว ๆ)

```
        T1   T2
   ช่องขาว (ซ้ายหุ่น)
  UL ─────────── UR
START ─ J1 ─ J2 ─ J3 ─ J4 ─┤ เหลือง
  DL ─────────── DR
   ช่องดำ (ขวาหุ่น)
        B1   B2
```

- U = แถวฝั่งซ้ายหุ่น (ฝั่งช่องขาว) · D = แถวฝั่งขวาหุ่น (ฝั่งช่องดำ)
- T1/B1 อยู่ปลายเส้นแนวตั้งที่ J2 · T2/B2 อยู่ปลายเส้นที่ J3
- ทีมซ้ายและทีมขวาใช้ชื่อจุดเดียวกัน เพราะช่องขาวอยู่ซ้ายหุ่นเสมอ

## บล็อคหมวด "ภารกิจส่งด่วน"

| บล็อค | ใช้ทำอะไร |
|---|---|
| `ไปจาก [จุด] ถึง [จุด]` | ตั้งจุดเริ่มแล้ววิ่งไปจุดปลายทาง |
| `ไปที่ [จุด]` | วิ่งจากตำแหน่งล่าสุดที่หุ่นจำไว้ |
| `ตั้งตำแหน่งหุ่นที่ [จุด]` | บอกหุ่นว่าอยู่ไหน **ใช้ทุกครั้งหลัง RETRY: ตั้งที่ START** |
| `ตำแหน่งปัจจุบัน` | เลขจุดที่หุ่นคิดว่าอยู่ (ไว้แสดงบนจอตอนทดสอบ) |
| `ตั้งค่าการวิ่ง` | ความเร็ว (ต่ำสุด = ความเร็วฐานตอนอยู่กลางเส้น) และ KP/KD |
| `ตั้งค่าการเลี้ยว` | ความเร็วหมุน · เวลาหมุนแบบไม่มองเส้น · เวลาเดินหน้าก่อนเลี้ยว |
| `ตั้งค่ากลับหัว` | ความเร็วหมุน · เวลาหมุนแบบไม่มองเส้น · เวลาถอยก่อนหมุน |
| `ตั้งค่าการเข้าจุดปลายทาง` | เวลาเดินต่อหลังหยุดที่จุดวาง Box / START / Box เหลือง (ค่าติดลบ = ถอยกลับ) |
| `ตั้งค่าความเร็วเข้า Box` | ความเร็วตั้งแต่แยกรองสุดท้ายจนถึง Box (ค่าเริ่มต้น 30) |
| `ตั้งค่าหยุดหลังผ่านแยกสุดท้ายก่อนถึง Box` | 0 = หยุดเมื่อเซนเซอร์เห็นขอบกรอบ Box · ค่าบวก = หยุดตามเวลาหลังผ่านแยกสุดท้าย (กันดันกล่อง) |
| `ตั้งค่าการเข้าช่องขาว/ช่องดำ` | 0 = หยุดที่ขอบช่อง (ค่าเริ่มต้น) · ค่าบวก = เดินเข้าไป · ค่าติดลบ = ถอยกลับ |
| `ตั้งค่าเซนเซอร์ข้าง ADC6 … ADC7 …` | ใส่ค่าคาลิเบรตเซนเซอร์ข้างเอง (ไม่ต้องคาลิเบรตใหม่ทุกครั้ง) |
| `ตั้งค่าเลี้ยวด้วยเซนเซอร์ข้าง ใช้ … เดินต่อ … ms` | เปิด/ปิดการเลี้ยวด้วยเซนเซอร์ข้าง และระยะเดินต่อหลังเซนเซอร์ข้างเห็นเส้น |

ทิศของหุ่นเมื่อตั้งตำแหน่ง:
- **START, J1–J4** → หันหน้าเข้ากลางสนาม
- **Box, เหลือง, ช่องขาว, ช่องดำ** → หันหน้าเข้าปลายเส้น (หุ่นกลับหัวเองก่อนออกเดินทาง)

สัญลักษณ์บนจอ:
- **รูป ✗** = วิ่งแล้วหาเส้นไม่เจอเกินเวลา ให้ขอ RETRY แล้วใช้ `ตั้งตำแหน่งหุ่นที่ START`
- **หน้างง (Confused)** = ยังไม่ได้คาลิเบรต ให้ใช้ `SensorCalibrate` หรือ `SETColorLine` ก่อน

ระหว่าง `SensorCalibrate` บล็อคนำทางจะไม่ทำงาน (ถึงจะใส่ไว้ใต้ "เมื่อกดปุ่ม A" ก็ตาม) เพราะการคาลิเบรตใช้ปุ่ม A

## ตัวอย่าง: เที่ยวเก็บ Box UL

```blocks
PTKidsBITRobot.SensorCalibrate()
PTKidsMission.setPosition(MissionPoint.START)
input.onButtonPressed(Button.B, function () {
    PTKidsBITRobot.servoWrite(Servo_Write.P12, 90)   // เปิดกริปเปอร์ (มุม 90/20 เป็นตัวอย่าง ใช้มุมจริงของหุ่น)
    PTKidsMission.goTo(MissionPoint.UL)
    PTKidsBITRobot.servoWrite(Servo_Write.P12, 20)   // หนีบ
    PTKidsMission.goTo(MissionPoint.START)
    PTKidsBITRobot.servoWrite(Servo_Write.P12, 90)   // ปล่อย
})
```

## ภารกิจอัตโนมัติ (เก็บครบ 8 กล่อง + กล่องเหลือง)

หุ่นคิดลำดับเก็บกล่องที่เร็วที่สุดเองบน micro:bit แล้ววิ่ง: หยิบกล่อง → ส่งเข้าช่องสีเดียวกัน ครบ 8 กล่อง → หยิบกล่องเหลืองกลับ START

| บล็อค | ใช้ทำอะไร |
|---|---|
| `ใส่สีกล่องด้วยปุ่ม A=ดำ B=ขาว` | ไฟกะพริบ = ช่องที่ถาม วนตามเข็มนาฬิกา UL → T1 → T2 → UR → DR → B2 → B1 → DL (แถวบนของจอ = ฝั่งช่องขาว) ครบแล้วเล่นเพลงสั้น ๆ และแสดงสรุป ไฟติด = ดำ ถ้าไม่ใช่ดำ 4 ขาว 4 แสดง X ให้ใส่ใหม่ |
| `ตั้งสีกล่องที่ [จุด] เป็น [ดำ/ขาว]` | ใส่สีด้วยบล็อคแทนปุ่ม (ใช้ตอนซ้อม) |
| `ตั้งค่ากริปเปอร์ แขน P8 ยกขึ้น … ลดลง … มือจับ P12 อ้า … หนีบ …` | มุมเซอร์โวที่ใช้หยิบ/ยก/วาง (ต้องวัดมุมแขน P8 ของหุ่นตัวเอง) |
| `เริ่มภารกิจอัตโนมัติ` | เริ่มจาก START ถ้าพลาด หุ่นหยุด → RETRY วางที่ START แล้วเรียกบล็อคนี้อีกครั้ง หุ่นทำต่อเฉพาะกล่องที่ยังไม่ส่ง |
| `เริ่มภารกิจอัตโนมัติใหม่ทั้งหมด` | ลืมว่ากล่องไหนส่งแล้ว (รอบแข่งใหม่) |
| `ข้ามกล่องที่ [จุด]` | บอกว่ากล่องนี้ไม่ต้องเก็บ / ส่งแล้ว |
| `จำนวนกล่องที่ส่งแล้ว` | 0–8 |

ขั้นตอนต่อหนึ่งกล่อง: แขนลง + อ้า → วิ่งเข้ากล่อง (ทางตรงเสมอ) → หนีบ + ยกแขน → วิ่งไปช่องสี (ลดแขนตอนหยุดที่แยกสุดท้ายก่อนเข้าช่อง) → อ้า + ยกแขนขึ้น

บล็อค `ลดแขนที่แยกก่อนถึงช่องขาว/ช่องดำ [เปิด/ปิด]` เปิดอยู่เป็นค่าเริ่มต้น ใช้กับบล็อค `ไปที่` ทุกครั้งที่ปลายทางเป็นช่องขาวหรือช่องดำด้วย
ระหว่างวิ่ง หุ่นจะไม่เลี้ยวหรือกลับหัวบนแยกที่อยู่ติดกล่องที่ยังวางอยู่ (กันตัวหุ่นกวาดกล่อง) ถ้าไม่มีเส้นทางแบบนั้นจริง ๆ จะใช้เส้นทางปกติ

ตัวอย่างโปรแกรมแข่งอยู่ในไฟล์ `test.ts`: เปิดเครื่อง → คาลิเบรต → ใส่สี → วางที่ START กด B = เริ่ม/RETRY · กด A+B = รอบใหม่

## เซนเซอร์ข้าง ADC6 (ซ้าย) / ADC7 (ขวา)

เซนเซอร์ 2 ตัวริมซ้าย-ขวาใต้หุ่น อยู่ระหว่างแถวเซนเซอร์หลักกับล้อ
- `SensorCalibrate` คาลิเบรตให้พร้อมเซนเซอร์หลัก (วางบน **ช่องดำ** ให้ทั้งหุ่นอยู่ในช่อง) และพิมพ์ค่า `Side Line` / `Side Ground` ทาง Serial
- เมื่อคาลิเบรตแล้ว ก่อนเลี้ยว 90° หุ่นจะเดินหน้าจนเซนเซอร์ข้างเห็นเส้นตัด แล้วเดินต่ออีกเล็กน้อย (ค่าเริ่มต้น 100 ms) จึงหมุน ตำแหน่งก่อนหมุนจะเท่ากันทุกครั้ง ไม่ขึ้นกับความเร็วหรือแบตเตอรี่
- จูน: ดูตอนหุ่นหยุดก่อนหมุน **แกนล้อควรอยู่ตรงเส้นตัด** ล้อยังไม่ถึง → เพิ่ม ms ล้อเลย → ลด ms
- ถ้าปิด หรือยังไม่คาลิเบรตเซนเซอร์ข้าง หุ่นจะใช้เวลา "เดินหน้าก่อนเลี้ยว" แบบเดิม

## เข้าหา Box แบบทางตรงเสมอ

Box อยู่ห่างแยกแค่ 8–10 ซม. ถ้าหุ่นเลี้ยวที่แยกติดกับ Box ตัวหุ่นจะกวาดโดนกล่อง
ตัวหาเส้นทางจึง **ไม่เลี้ยวที่แยกที่ติดกับ Box ปลายทาง** แต่จะเลี้ยวที่แยกก่อนหน้านั้น แล้ววิ่งตรงผ่านแยกนั้นเข้าหา Box เช่น START → UL:
ออกจาก START → หยุดที่ J3 → เลี้ยวซ้าย → หยุดที่แยกแถวบน → เลี้ยวซ้าย → ผ่าน 1 แยก → เข้า UL

(บล็อค `ตั้งค่ากริปเปอร์` จากเวอร์ชัน 0.3.0 ไม่จำเป็นแล้ว ซ่อนจากรายการบล็อค แต่โปรแกรมเก่ายังคอมไพล์ได้)

## วิ่งเร็วบนทางตรง

`ตั้งค่าวิ่งเร็วทางตรง ความเร็ว [70] เบรกก่อนถึงแยก [10] ซม.`
- ช่วงที่หุ่นแค่วิ่งผ่านแยก ใช้ความเร็วนี้ตลอดช่วง (เร่งขึ้นทีละนิดเพื่อไม่ให้สะบัดหลุดเส้น)
- ช่วงสุดท้ายก่อนแยกที่ต้องหยุดหรือเลี้ยว วิ่งเร็วแล้วชะลอเป็นความเร็วต่ำสุดเมื่อเหลือระยะเบรก
- หุ่นวัดความเร็วจริงของตัวเองจากเวลาวิ่งระหว่างแยก (ช่วงแรกของการเปิดเครื่องจะเบรกเร็วกว่าที่ต้องการเล็กน้อย)
- ตั้ง "สูงสุด" ใน `ตั้งค่าการวิ่ง` ให้มากกว่าความเร็วนี้ เช่น สูงสุด 100 กับ วิ่งเร็ว 70
- ความเร็ว 0 = ปิด (ค่าเริ่มต้น)

`ตั้งค่าเวลากริปเปอร์ หนีบ [250] ms ปล่อย [200] ms` — ภารกิจอัตโนมัติรอเซอร์โวเฉพาะตอนหนีบและตอนปล่อย ส่วนการยก/ลดแขนอื่น ๆ ทำไปพร้อมกับตอนหุ่นวิ่ง

## เลี้ยวแบบไม่หยุด

`เลี้ยวแบบไม่หยุด [เปิด]` — หุ่นวิ่งเข้าแยกแล้วหมุนต่อทันที หมุนเจอเส้นแล้ววิ่งตามเส้นต่อเลย ไม่หยุด 3 ครั้งแบบเดิม (หยุดบนแยก / หยุดก่อนหมุน / หยุดหลังหมุน) กลับหัวยังหยุดเหมือนเดิม
ตอนเลี้ยวเข้าช่องขาว/ดำ หุ่นลดแขนระหว่างหมุนเลย ไม่หยุดรอ

## หยุดที่แยกก่อนถึง Box (กริปเปอร์ยื่นไกล)

บล็อค `หยุดที่แยกก่อนถึง Box [เปิด]` ให้หุ่นหยุดบนแยกสุดท้ายก่อนถึงกล่อง แทนการวิ่งไปจนเห็นขอบกรอบ Box ใช้เมื่อกริปเปอร์ยื่นออกไปหน้าเซนเซอร์จนชนกล่องก่อนเซนเซอร์ถึงขอบกรอบ
ปรับระยะต่อด้วย `ตั้งค่าการเข้าจุดปลายทาง Box … ms` (บวก = เดินหน้าต่อ, ลบ = ถอย) ตอนออกจากกล่อง หุ่นจะถอยกลับเท่าระยะนั้นแล้วออกจากแยกได้ทันที

## แสดงเหตุผลการหยุด (ใช้ตอนจูน)

`แสดงเหตุผลการหยุด [จริง]` เมื่อหุ่นหยุดที่ปลายทาง ไฟแถวบนสุดจะติด 1 ดวง:
- **ซ้าย** = หยุดเพราะเจอขอบกรอบ (Box / START / ช่องสี)
- **กลาง** = หยุดเพราะสุดปลายเส้น
- **ขวา** = หยุดเพราะหมดเวลา `หยุดหลังผ่านแยกสุดท้ายก่อนถึง Box`

## ออกจาก START / ช่องขาว / ช่องดำ

หลังวางกล่องในช่องสี (หรือกลับเข้า START) หุ่นจะ **ถอยตามเส้นออกมาจนถึงแยกที่ใกล้ที่สุด** (ข้ามขอบกรอบช่องไปก่อน) แล้วเลี้ยวที่แยกนั้นเลย ไม่ต้องกลับหัวในช่อง

## ลำดับการจูนบนสนามจริง

1. **คาลิเบรต** ด้วย `SensorCalibrate` (วางเซนเซอร์ทั้ง 6 ตัวบนช่องดำ แล้วกด A จากนั้นวางบนพื้นขาวแล้วกด A)
   อ่านค่าจาก Serial แล้วใส่ใน `SETColorLine` จะได้ไม่ต้องคาลิเบรตใหม่ทุกครั้ง
2. **การวิ่ง**: `ไปจาก START ถึง J4` ปรับ KP/KD จนวิ่งนิ่ง
3. **การเลี้ยว**: `ไปจาก START ถึง UL` ถ้าเลี้ยวแล้วเลยเส้น ลดเวลาหมุนเร็ว ถ้าหมุนแล้วจอดผิดเส้น เพิ่มเวลาเดินหน้าก่อนเลี้ยว
4. **ออกจาก Box และกลับหัว**: หุ่นจะถอยหลังจนเซนเซอร์เจอแยกที่ใกล้ Box ที่สุด แล้วเลี้ยวหรือกลับหัวบนแยกนั้น
   - ทดสอบด้วย `ไปจาก T1 ถึง J2` (ต้องถอย กลับหัว แล้วหยุดที่ J2)
   - ถ้าถอยแล้วหยุดทันทีที่ขอบกรอบ Box ให้เพิ่มค่า "ไม่นับขอบกรอบช่วงแรก"
   - เวลาหมุนเร็วตอนกลับหัวควรพาหุ่นหมุนเกิน 90° ก่อนเริ่มมองหาเส้น จะได้ไม่หยุดที่แขนของแยก
5. **เข้าจุดปลายทาง**: หุ่นชะลอเป็น "ความเร็วเข้า Box" ตั้งแต่แยกรองสุดท้าย แล้วหยุดเมื่อเซนเซอร์ 4 ตัวขึ้นไปเห็นขอบกรอบ Box
   - ยังดันกล่อง → ใช้ `ตั้งค่าหยุดหลังผ่านแยกสุดท้ายก่อนถึง Box` เริ่มที่ 300 ms แล้วปรับจนกริปเปอร์ครอบกล่องพอดี (ค่าน้อย = หยุดเร็วขึ้น)
   - หยุดก่อนถึงกล่อง กริปเปอร์ไม่ครอบ → ใส่เวลาเข้า Box เป็นบวก (เช่น 100)
   - ช่องขาว/ช่องดำ: ถ้าหุ่นล้ำเข้าช่องมากเกินไปแม้ตั้งเป็น 0 (เพราะไถลตอนเบรกที่ความเร็วสูง) ให้ใส่ค่าติดลบ เช่น -100
   - เวลาทั้งหมดนี้ใช้ความเร็วต่ำสุดใน `ตั้งค่าการวิ่ง` ถ้าเปลี่ยนความเร็ว ต้องจูนเวลาใหม่

## ข้อจำกัด

- ใช้ได้กับสนามภารกิจส่งด่วนเท่านั้น และไม่ข้ามช่องว่างที่ไม่มีเส้น
- รองรับเส้นดำบนพื้นขาว
- ค่าเวลาเริ่มต้นเป็นค่าประมาณ ต้องจูนกับหุ่นจริง
